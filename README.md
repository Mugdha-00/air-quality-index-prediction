
# 🌍 Air Quality Index (AQI) Prediction Using Machine Learning

## 📌 Project Overview
This project uses machine learning regression techniques to predict the Air Quality Index (AQI) based on air pollution indicators. It explores pollutant data and compares different regression models to evaluate their predictive performance.

## 🎯 Objectives
- Analyze air quality data using Python.
- Perform data cleaning and exploratory data analysis.
- Identify relationships between air pollutants and AQI.
- Build and compare machine learning regression models.
- Evaluate model performance using standard metrics.
- Improve model performance through hyperparameter tuning.

## 🛠️ Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Jupyter Notebook
- **Models:** Random Forest Regression, Linear Regression
- **Optimization:** GridSearchCV

## 📊 Project Workflow
1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature selection
4. Model training and testing
5. Model comparison
6. Performance evaluation using MAE, MSE, and R² score
7. Hyperparameter tuning
8. Actual vs. predicted value visualization and feature importance analysis

## 🚀 How to Run
1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `AQI.ipynb` and run the notebook cells in order.

Ensure the dataset is in the same directory as the notebook.

## 📈 Model Evaluation
The project evaluates regression models using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

Refer to the notebook outputs for the actual evaluation results.
